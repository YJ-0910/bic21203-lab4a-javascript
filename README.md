## Lab Description
This lab focuses on JavaScript functions, event handling,
conditional statements, loops, and DOM manipulation.

## Question 1: Interactive Text Changer
This webpage changes the paragraph text from
"Welcome to my website!" to "Hello there!"
when the Change Message button is clicked.

## Question 2: Smart Number Validator
This webpage accepts user input and checks whether
the number is lower than, higher than, or equal to 10.
It also handles invalid and empty inputs.

## Question 3: Dynamic Number Generator
This webpage generates a numbered list from 1 to 5
using a JavaScript for loop.
Repeated clicks do not duplicate the list.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open the Q1, Q2, or Q3 folder.
5. Right-click index.html.
6. Select "Open with Live Server".
7. Test the webpage in your browser.
